## 🛠️ Tech Stacks Included
- **WebGL Libraries**: Three.js, React Three Fiber (R3F), Drei, GLTFLoader, DRACOLoader, TSL
- **Animation Engines**: GSAP, GSAP ScrollTrigger, Framer Motion, HTML5 Canvas Scrubbing
- **Frameworks**: Next.js 15 (App Router), React 18, Vite, Tailwind CSS, Lucide, FontAwesome
- **Optimization**: Draco Mesh Compression (up to 95% bandwidth savings), WebP textures, CSS radial GPU fallback gradients
